# OIBSIP Level 2 Task 4: Login Authentication System

A client-side authentication system built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- User Registration with username and email
- Password validation: minimum 8 characters, 1 number required
- Duplicate username/email prevention
- Login with username or email
- Secure password storage using SHA-256 hashing
- Protected Dashboard page accessible only after login
- Session management using localStorage
- Logout functionality
- Form validation and error handling
- Responsive UI

## How to Run
Open `index.html` in any web browser.

## Tech Stack
HTML5, CSS3, Vanilla JavaScript, Web Crypto API, localStorage

## Note
This is a front-end demo. For production, use a backend with proper security.
