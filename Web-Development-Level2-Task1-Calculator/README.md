# OIBSIP Level 2 Task 1: Calculator

A fully functional browser-based calculator built for Oasis Infobyte Internship.

## Features
- Basic arithmetic: Addition, Subtraction, Multiplication, Division
- Numeric buttons 0-9 and decimal point
- Display screen for current input and results
- Equals button to evaluate expressions
- Clear button to reset and Backspace to delete last character
- Operator chaining: e.g. `5 + 3 × 2`
- Division by zero error handling
- Responsive button layout using CSS Grid
- Built with Vanilla JavaScript - no eval() used

## How to Run
Open `index.html` in any web browser.

## Tech Stack
HTML5, CSS3, Vanilla JavaScript
