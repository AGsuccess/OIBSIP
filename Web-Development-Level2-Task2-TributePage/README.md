# OIBSIP Level 2 Task 2: Tribute Page

A responsive tribute page dedicated to Elon Musk, built for Oasis Infobyte Internship.

## Features
- Hero section with name, tagline, and prominent image
- Detailed biography section with 4 paragraphs
- Timeline of key achievements and milestones
- Styled quote block with notable quote
- Responsive design for mobile and desktop
- Uses 2 background colors and 2 font styles for visual hierarchy
- Image sourced from Unsplash

## How to Run
Open `index.html` in any web browser.

## Tech Stack
HTML5, CSS3, Google Fonts
