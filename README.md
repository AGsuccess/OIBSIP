# OIBSIP - Oasis Infobyte Web Development Internship

This repository contains all the tasks I completed during the **Oasis Infobyte Web Development Internship Program [OIBSIP]**. 
The internship is structured into 2 levels with 3-4 tasks each, designed to build real-world web development skills using HTML5, CSS3, and JavaScript.

---

## 📌 About OIBSIP

Oasis Infobyte provides a virtual internship program to help students and beginners gain hands-on experience in Web Development, Android Development, Data Science, and more. 
Each task has specific objectives, a checklist, and requires a LinkedIn demo post + GitHub submission.

---

## 🛠️ Tech Stack Used
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Storage**: localStorage
- **Tools**: VS Code, Git, GitHub
- **Design**: Responsive Design, Flexbox, Grid

---

## 📂 LEVEL 1 TASKS

### **Task 1: Landing Page**
**Objective**: Create a responsive and visually appealing landing page for a fictional or real product, service, or business. 
**Key Features**:
- Hero section with CTA button
- Navigation bar with smooth scrolling
- About, Features, and Contact sections
- Responsive layout for mobile and desktop
- Clean typography and color scheme

**Skills Learned**: Page structure, CSS layout, responsive design, user-first design

---

### **Task 2: Portfolio Website**
**Objective**: Design and build a personal portfolio website to showcase skills, projects, and contact information. 
**Key Features**:
- Header with name, role, and profile photo
- About Me section
- Skills section with icons
- Projects section with descriptions and links
- Contact form and social media links
- Responsive and professional UI

**Skills Learned**: Personal branding, content organization, CSS styling, responsive grids

---

### **Task 3: Temperature Converter Website**
**Objective**: Build an interactive web tool that converts temperature values between Celsius, Fahrenheit, and optionally Kelvin, with real-time input validation. 
**Key Features**:
- Dropdown to select input and output units
- Input validation: no empty values, no values below absolute zero
- Real-time conversion on button click
- Clean UI with error messages
- Responsive design

**Skills Learned**: DOM manipulation, form validation, math logic, event handling

---

## 📂 LEVEL 2 TASKS

### **Task 1: Calculator**
**Objective**: Build a fully functional browser-based calculator capable of performing basic arithmetic operations with a user-friendly button interface. 
**Key Features**:
- Buttons for digits 0-9 and operators +, -, *, /
- Display screen for input and output
- Clear [C] and Backspace functionality
- Error handling for division by zero and invalid expressions
- Keyboard support

**Skills Learned**: JavaScript logic, state management, event listeners, UI/UX for tools

---

### **Task 2: Tribute Page**
**Objective**: Design and build a visually engaging tribute page dedicated to a historical figure, scientist, artist, or public figure you admire. 
**Key Features**:
- Hero section with name and image
- Biography section
- Timeline of major achievements
- Inspirational quote section
- Footer with reference links
- Responsive and aesthetically pleasing design

**Skills Learned**: Storytelling with web, typography, layout design, semantic HTML

---

### **Task 3: To-Do Web App**
**Objective**: Develop an interactive to-do list application that allows users to manage daily tasks with add, complete, edit, and delete functionality, organised into pending and completed lists. 
**Key Features**:
- Add new tasks with date/time
- Mark tasks as complete/incomplete
- Edit and delete tasks
- Separate sections for Pending and Completed tasks
- Data persistence using localStorage
- Task counter

**Skills Learned**: CRUD operations, localStorage, array methods, dynamic DOM rendering

---

### **Task 4: Login Authentication System**
**Objective**: Build a simple client-side authentication system featuring user registration, login validation, and access to a protected page. 
**Tech Approach Used**: Frontend only - HTML/CSS/JavaScript with localStorage 
**Key Features**:
- Registration page with username/email + password
- Password validation: min 8 chars, 1 number
- Duplicate user check
- Login page with credential validation
- Generic error messages for security
- Protected Dashboard page - redirects if not logged in
- Logout button that clears session
- Basic password hashing using SHA-256
- Form validation on both pages

**Skills Learned**: Client-side auth, session management, security basics, routing with JS
