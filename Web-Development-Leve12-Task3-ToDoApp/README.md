# OIBSIP Level 2 Task 3: To-Do Web App

An interactive task manager built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- Add new tasks with input field
- Separate Pending and Completed task lists
- Mark tasks as complete/incomplete
- Edit task text inline
- Delete tasks permanently
- Task counters for pending and completed
- Timestamp for when task was added/completed
- Data persists using localStorage
- Empty state messages
- Responsive design

## How to Run
Open `index.html` in any web browser.

## Tech Stack
HTML5, CSS3, Vanilla JavaScript, localStorage
